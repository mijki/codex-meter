# Code of Conduct

Codex Meter is a public open-source project. Everyone participating in the project is expected to act respectfully and professionally.

## Expected behavior

- Be direct, constructive, and factual.
- Critique ideas, not people.
- Respect privacy and security boundaries.
- Keep discussions focused on the repository and its users.
- Disclose mistakes quickly and correct them.

## Unacceptable behavior

- Harassment, threats, or discriminatory language.
- Publishing secrets, credentials, private prompts, or other sensitive data.
- Deliberately misrepresenting telemetry accuracy or data provenance.
- Using issues or pull requests to attack contributors.

## Enforcement

Maintainers may remove content, close discussions, or reject contributions that violate this code of conduct.

## Reporting

Report misconduct through the repository's normal issue or maintainer channel, while omitting sensitive data from the report itself.
