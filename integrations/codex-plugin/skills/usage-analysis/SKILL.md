# Codex Meter usage analysis

Use this skill only when the user asks to interpret data already collected by Codex Meter.

1. Open Codex Meter and select Usage Burn.
2. Report the displayed evidence, calculation method, accuracy classification, confidence, and missing signals.
3. Describe correlations, not causes, unless the underlying interface reports a direct relationship.
4. Never call account-level quota movement exact project, chat, or turn consumption.
5. Do not request or expose prompts, responses, tool arguments, command output, transcripts, credentials, or repository contents.

If Codex Meter is unavailable, explain that no local data can be queried. Do not estimate or start a model turn to manufacture telemetry.
